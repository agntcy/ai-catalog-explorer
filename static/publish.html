Publish your AI Catalog

An AI Catalog is one JSON file that lists the AI artifacts your domain offers: MCP servers, agents, skills. Write it, serve it, and tools can find it.

1. Write the catalog

Fill in the details and the file is written for you. It is checked as you type. Nothing is sent anywhere except to this page's own checker.

      2. Serve it
      
    
      
      
      Serve the file at https://example.com/.well-known/ai-catalog.json. Tools that probe a domain look there first. The preferred media type is application/ai-catalog+json; a plain application/json is accepted too.
