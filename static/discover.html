Exploring…

Looking for a catalog and checking it. This can take a few seconds.

    The catalog document

    The catalog as the server sent it. The tree is for reading: open and close parts of it, and see what each signature checked out as. "As served" shows the exact bytes the signatures cover.

    What it lists

    Each entry points to one AI artifact: an MCP server, an agent, a skill, an API description or another catalog. Entries with trust information show what was checked.

      How it was found

      The web requests made while looking for the catalog, in order. The search stops at the first catalog found. A Link header or link element is read from the home page response without another request.

        Only the root entries are verified. The explorer has no list of authorized catalog operators, so a catalog signature is checked but never counted as authorized.
